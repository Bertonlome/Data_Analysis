──────────────────────────────────────────────────────────────────────────────
  The quadrant plot combines all questionnaire families (SUS, TiA, Oversight,
  Perceived Control, NASA-TLX polarity-corrected, Trust/Risk VAS) into two
  participant-level coordinates:
    x = mean(TARP-S - TARS),  y = mean(TARP-F - TARS).
  Positive values mean better than TARS baseline.

  Relative mode preference is summarized by mode balance:  (y - x).
  Positive values indicate stronger tilt toward TARP-F; negative values toward TARP-S.

──────────────────────────────────────────────────────────────────────────────
  HOW TO READ THE QUADRANT
──────────────────────────────────────────────────────────────────────────────
  Q1 (+x, +y): both modes better than baseline TARS.
  Q2 (-x, +y): only TARP-F better than baseline.
  Q3 (+x, -y): only TARP-S better than baseline.
  Q4 (-x, -y): both modes worse than baseline.

  Relative mode preference is read against the diagonal y=x:
    y > x  -> tilt toward TARP-F
    y < x  -> tilt toward TARP-S
